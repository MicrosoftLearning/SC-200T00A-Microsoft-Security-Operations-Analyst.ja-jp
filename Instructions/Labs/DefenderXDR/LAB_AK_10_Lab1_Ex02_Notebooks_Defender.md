# ラーニング パス 10 - ラボ 1 - 演習 2 - Microsoft Sentinel でのデータ レイク ノートブックを使用した脅威ハンティング

## ラボのシナリオ

あなたは Microsoft Sentinel を実装した企業で働いているセキュリティ運用アナリストです。 Microsoft Sentinel Notebooks を使った脅威ハンティングの利点を調査する必要があります。 Notebooks は次の用途に使用できます。

- 一部の Python 機械学習機能など、Microsoft Sentinel ではすぐに使うことのできない分析を実行する。
- カスタムのタイムラインやプロセス ツリーなど、Microsoft Sentinel ではすぐに使うことのできないデータ視覚化を作成する。
- オンプレミスのデータ セットなど、Microsoft Sentinel の外部にあるデータ ソースを統合する

>**重要:** ラーニング パス #10 のラボ演習は、*スタンドアロン*環境にあります。 ラボを完了せずに終了する場合は、構成を再実行する必要があります。

### このラボの推定所要時間: 30 分

### タスク 1: データ レイク ノートブックを使用してハンティングする

このタスクでは、Microsoft Sentinel データ レイクでのノートブックについて学習します。 Visual Studio Code を使用してノートブックにアクセスし、多数の Visual Studio Code 拡張機能をインストールします。

>**注:** Visual Studio Code は既にラボ VM にインストールされています。 あらかじめ Visual Studio Code、Jupyter Notebook、Python コーディングの経験を積んでおくことをお勧めします。

1. 管理者として **WIN1** 仮想マシンにログインします。パスワードは **Pa55w.rd** です。  

1. Microsoft Edge ブラウザーで、Defender XDR (`https://security.microsoft.com`) に移動します。

1. **[サインイン]** ダイアログ ボックスで、ラボ ホスティング プロバイダーから提供された**テナントの電子メール** アカウントをコピーして貼り付け、**[次へ]** を選択します。

1. **[パスワードの入力]** ダイアログ ボックスで、ラボ ホスティング プロバイダーから提供された**テナントパスワード**をコピーして貼り付け、**[サインイン]** を選択します。

    >**注:**  パスワードの代わりに "一時アクセス パス" (TAP) を入力するように求められる場合があります。** これはリソース タブにも表示されます。TAP を入力する画面が表示された場合は、値をコピーして貼り付けて **[サインイン]** を選択してください。

1. Microsoft Defender のナビゲーション メニューで、下スクロールして **[Microsoft Sentinel]** セクションを展開します。

1. Microsoft Sentinel の *[データ レイク探索]* を展開して **[ノートブック]** を選択します。

1. *[ノートブック]* ページには、データ レイク Jupyter ノートブックを使用するために実行するステップのリストが表示され、利用できるリソースへのリンクもあります。

1. タスク バーに移動し、Visual Studio Code アイコンを選択します。

    >**注:** 特に指定がない限り、常に *Microsoft* が発行した拡張機能をインストールしてください。

1. 左側のメニュー バーで、拡張機能アイコンを選択します。

1. [拡張機能] の検索バーで、*Python* を検索して **[インストール]** を選択します。

1. [拡張機能] の検索バーで、*Jupyter Notebooks* を検索し、まだインストールされていない場合は **[インストール]** を選択します。

1. [拡張機能] の検索バーで、*GitHub Copilot* を検索して **[インストール]** を選択します。

1. [拡張機能] の検索バーで、*Microsoft Sentinel* を検索して **[インストール]** を選択します。

1. すべての拡張機能のインストールが完了するまで待ちます。

1. キーボードで、Ctrl + Shift + p キーを選択して、上部のバー内のコマンド オプションを開きます。

1. **[MCP: サーバーの追加]** を探して、そのオプションを選択します。

1. [HTTP] オプションを選択し、URL: `https://sentinel.microsoft.com/mcp/data-exploration>` を入力します。

1. **Enter** キーを押します。これで既定のサーバー ID が使用されます。

1. サーバーを認証する画面が表示されたら、**[許可]** を選択します。

1. アカウントの種類では、**[職場または学校アカウント]** (組織で割り当てられたアカウント) オプションを選択して **[続行]** を選択します。

1. このラボ用に提供された資格情報を入力します。

1. **[はい、すべてのアプリ]** を選択します。

1. 自分のデバイスが登録されたら、**[完了]** を選択します。

1. サイド バーでまだ開いていない場合は、上部のメニュー バーの **[チャットの切り替え]** アイコンを選択します。

    >**ヒント:** 検索バーの横にあります。またはキーボードの **Ctrl + Shift + I** キーを選択してください。

1. 次の例のような Copilot プロンプトを入力します。

- デバイス上の悪意のあるアクティビティをハンティングするにはどのテーブルを使うといいですか
- ハンティング クエリには SecurityEvent テーブルのどの列を使うといいですか
- 私のワークスペース内の過去 90 日間の SecurityEvent データをクエリで検索して、その結果を悪意のあるアクティビティ上位 5 件として要約して、表形式でまとめてください

1. MCP サーバーの認証の画面が表示されたら、**[許可]** を選択し、自分のラボ資格情報をもう一度選択します。

1. 結果またはクエリ候補が MCP サーバーから返された後の任意の時点で、結果や提案をまとめたノートブックを作成するよう依頼してみてください。

1. ノートブックを作成するかどうかを尋ねる画面が表示されたら、**[許可]** を選択します。

1. **Microsoft Sentinel** 拡張機能にサインインさせるかどうかを尋ねる画面が表示されたら、**[許可]** を選択し、自分のラボ資格情報をもう一度選択します。

1. Jupyter Notebook が作成されたら、コード セルとマークダウン セルを確認します。

1. このノートブックを保存するには、右下にある **[保持]** を選択します。

1. 左側のメニュー バーから **Microsoft Sentinel** の盾のアイコンを選択します。**

1. **[LAKE TABLES]** セクションで、**defender** テーブルを展開してから **Security & Audits** テーブルを展開します。

1. *SecurityEvent* テーブルのスキーマが表示されます。

1. **[NOTEBOOK SAMPLES]** セクションで、[Tutorials] を展開し、**01_GettingStartedwithSentineldatalake** チュートリアル ノートブックを選択します。**

1. この Jupyter Notebook が開いたら、さまざまなタブ、コード セル、マークダウン セルを確認します。

>**注:** コード セルを実行してもかまいませんが、このラボでは実行する必要はありません。 時間が許すかぎり、発表者が手助けします。

## これでラボは完了です
